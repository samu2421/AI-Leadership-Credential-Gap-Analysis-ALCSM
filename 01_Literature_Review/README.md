# 02_Literature_Review

## Purpose
Houses the theoretical grounding for the ALCSM framework: source materials, synthesis work, and the literature review chapter itself.

## What Belongs Here
- Annotated bibliography and citation exports (BibTeX/RIS)
- Search strategy / inclusion-exclusion documentation
- Theme and synthesis matrices mapping sources to ALCSM constructs
- Literature review chapter drafts

## Naming Conventions
- `ALCSM_LitReview_<Description>_v<Major>.<Minor>.<ext>`
  - e.g., `ALCSM_LitReview_ThemeMatrix_v2.1.xlsx`
  - e.g., `ALCSM_LitReview_ChapterDraft_v1.4.docx`

## Versioning Rules
- Never overwrite a draft once it has been shared for feedback — increment MINOR version for each revision round.
- Bump MAJOR version when the review's scope or structure changes materially (e.g., new search conducted, new theme taxonomy).
- Superseded drafts move to `16_Archive/02_Literature_Review/`, preserving the full revision history.
