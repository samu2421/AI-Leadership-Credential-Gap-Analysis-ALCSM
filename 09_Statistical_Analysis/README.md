# 10_Statistical_Analysis

## Purpose
Quantitative analysis supporting the thesis's findings: descriptive statistics, hypothesis tests, and gap-analysis computations.

## What Belongs Here
- Statistical output reports and result tables
- Model/test results (regression, correlation, significance tests, etc.)
(Executable analysis code lives in `15_Scripts`; this folder holds the resulting reports and outputs.)

## Naming Conventions
- `ALCSM_Stats_<Analysis>_<Description>_v<Major>.<Minor>.<ext>`
  - e.g., `ALCSM_Stats_GapAnalysis_Results_v1.1.xlsx`

## Versioning Rules
- Standard MAJOR.MINOR versioning; re-runs following data corrections bump the MINOR version.
- Retain every prior output version for audit trail — never overwrite a completed analysis run.
