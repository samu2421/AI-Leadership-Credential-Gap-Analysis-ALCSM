# 04_Database_Design / 04_ER_Diagram

## Purpose
Visual documentation of the ALCSM database's entity-relationship structure.

## What Belongs Here
- Source diagram files (e.g., `.drawio`, `.dbml`, `.fig`)
- Exported final images (`.png`, `.svg`, `.pdf`) for use in documentation and the thesis manuscript

## Naming Conventions
- `ALCSM_DB_ERDiagram_v<Major>.<Minor>.<Patch>.<ext>`
  - e.g., `ALCSM_DB_ERDiagram_v1.0.1.drawio` / `ALCSM_DB_ERDiagram_v1.0.1.png`

## Versioning Rules
- The diagram's version must always match the schema version (`02_Schema`) it depicts — update it whenever the schema changes.
- Never overwrite a prior diagram version; superseded diagrams move to `17_Archive/04_Database_Design/04_ER_Diagram/`.
