# 03_Framework_Development

## Purpose
Home of the ALCSM conceptual framework: its constructs, dimensions, and theoretical model. **The framework is frozen at v1.0 as of Task 4** — this folder now holds that frozen baseline plus any post-freeze extension work for later tasks.

## What Belongs Here
- Framework diagrams and conceptual models
- Construct/competency/dimension definitions and taxonomies
- Framework validation notes and expert-review feedback
- `CHANGELOG.md` tracking any post-freeze revisions

## Naming Conventions
- `ALCSM_Framework_<Description>_v<Major>.<Minor>.<ext>`
- Frozen release files are marked explicitly: `ALCSM_Framework_CoreModel_v1.0_FROZEN.<ext>`

## Versioning Rules
- **v1.0 is frozen and read-only.** Do not edit frozen files in place, under any circumstances.
- Any refinement after the freeze starts a new version (v1.1 for minor refinement, v2.0 for structural change) and must be logged in this folder's `CHANGELOG.md`, with the v1.0 baseline preserved untouched alongside it.
- Superseded pre-freeze drafts belong in `16_Archive/03_Framework_Development/`.
