# Protocols

## Purpose

This subfolder contains the structured collection and data-governance protocols for the ALCSM dataset. Each document is a self-contained research protocol, written to allow reproduction of the data collection process independent of the software implementation.

## Contents

| Document | Purpose |
|---|---|
| `ALCSM_LinkedIn_Collection_Protocol_v1.0.md` | Protocol governing collection of the LinkedIn profile dataset. |
| `ALCSM_JobPosting_Collection_Protocol_v1.0.md` | Protocol governing collection of the job posting dataset. |
| `ALCSM_Inclusion_Exclusion_Criteria_v1.0.md` | Consolidated inclusion and exclusion criteria for both datasets. |
| `ALCSM_Data_Quality_Guidelines_v1.0.md` | Data accuracy, consistency, and audit-trail principles applied across both datasets. |
| `ALCSM_Relationships_v1.0.md` | The logical relationships between datasets and the rationale for their independence during collection. |

## Status Note

Several documents in this folder contain explicit placeholders where eligibility criteria or other operational parameters have not yet been finalized. These are marked clearly within each document and must be resolved before real data collection begins. Placeholders are not to be treated as approved criteria.

## Versioning

Each document is independently versioned (`v1.0`, `v1.1`, …). A version increment accompanies any change to substantive content. Each document carries its own Revision History section.
