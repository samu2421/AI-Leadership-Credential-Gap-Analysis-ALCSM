# 13_Tables

## Purpose
All tables used in the thesis manuscript, in both source data and final formatted form.

## What Belongs Here
- Source data/spreadsheets underlying each table
- Final formatted table exports referenced by chapter and table number

## Naming Conventions
- `ALCSM_Tbl<ChapterNum>.<TableNum>_<Description>_v<Major>.<Minor>.<ext>`
  - e.g., `ALCSM_Tbl4.1_ReliabilityScores_v1.0.xlsx`

## Versioning Rules
- Table numbering must stay stable once referenced in a thesis draft, matching the rule used for `12_Figures`.
- Content revisions bump the version suffix rather than the table number; superseded versions move to `17_Archive/13_Tables/`.
