# 02_DPIA

## Purpose
Data Protection Impact Assessment documentation: the Article 35 screening that determines whether a full DPIA is required, and the full assessment itself where warranted.

## What Belongs Here
- DPIA screening note (the triggers checklist and its conclusion)
- Full DPIA draft and its finalised version, if screening indicates one is needed
- DPO review comments and sign-off (or written confirmation that no DPIA is required)
- Any risk-mitigation follow-ups raised during DPIA review

## Naming Conventions
- `ALCSM_Ethics_DPIAScreening_v<Major>.<Minor>[-STATUS].<ext>`
- `ALCSM_Ethics_DPIAFull_v<Major>.<Minor>[-STATUS].<ext>`

## Versioning Rules
- The screening note and the full DPIA are versioned independently — a full DPIA revision does not require re-versioning the screening that triggered it.
- A DPO-signed-off DPIA is immutable once signed; a materially changed processing operation requires a new DPIA version, not an edit.
- Prior versions are retained, never deleted, so the assessment's evolution remains auditable.
