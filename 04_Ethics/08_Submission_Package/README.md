# 08_Submission_Package

## Purpose
The frozen, as-submitted bundle sent to the ethics committee/DPO at each formal submission point — a snapshot, so what was actually reviewed is always reconstructable even as individual documents (application, DPIA, LIA, etc.) continue to evolve elsewhere in `04_Ethics/`.

## What Belongs Here
- A dated copy (or manifest listing exact file versions) of every document included in a given submission
- The cover letter/submission form used, if any
- Nothing here is a working draft — working drafts live in the other subfolders; this folder only holds frozen, submitted snapshots

## Naming Conventions
- `ALCSM_Ethics_SubmissionPackage_<YYYY-MM-DD>/` (one dated subfolder per submission event, containing the frozen copies or a manifest)

## Versioning Rules
- A submission snapshot is immutable from the moment it is sent — never edited, even if the working documents elsewhere are later revised.
- Each resubmission (e.g. after committee-requested changes) is a new dated snapshot, not an overwrite of the previous one.
