# 05_Ethics

## Purpose
IRB/ethics approval and compliance documentation for any human-subjects aspects of the ALCSM data collection and annotation work (e.g., expert annotators, survey participants).

## What Belongs Here
- IRB application and approval letters
- Consent forms and participant information sheets
- Data privacy / anonymization protocols
- IRB amendments and correspondence

## Naming Conventions
- `ALCSM_Ethics_<Description>_v<Major>.<Minor>[-STATUS].<ext>` — the project-wide pattern from `PROJECT_STRUCTURE.md` §4. Each of the nine subfolders below states the exact pattern for its own documents (e.g. `ALCSM_Ethics_ApplicationDraft_v0.1-DRAFT.md`).
  - **Exception:** `07_Institutional_Correspondence/` uses dated (not versioned) filenames instead, since those records are point-in-time snapshots rather than evolving documents — see that subfolder's own README.

*(Corrected P2 Session 4, 2026-07-30: this line previously required a trailing `_<YYYY-MM-DD>` date suffix, which none of the documents drafted in P2 Sessions 1–2 actually used — see `P2_Governance_QA_Report.md` finding D-1. The convention above now matches the files that exist.)*

## Versioning Rules
- Approved/signed documents are immutable once approved — never alter an approved document in place.
- Amendments are new versions that must reference the amendment date and the original approval they modify.
- All historical approvals and amendments are retained permanently; nothing in this folder is ever deleted.
