# 05_Ethics

## Purpose
IRB/ethics approval and compliance documentation for any human-subjects aspects of the ALCSM data collection and annotation work (e.g., expert annotators, survey participants).

## What Belongs Here
- IRB application and approval letters
- Consent forms and participant information sheets
- Data privacy / anonymization protocols
- IRB amendments and correspondence

## Naming Conventions
- `ALCSM_Ethics_<Description>_v<Major>.<Minor>_<YYYY-MM-DD>.<ext>` (date = approval or submission date where applicable)
  - e.g., `ALCSM_Ethics_IRBApproval_v1.0_2026-03-15.pdf`

## Versioning Rules
- Approved/signed documents are immutable once approved — never alter an approved document in place.
- Amendments are new versions that must reference the amendment date and the original approval they modify.
- All historical approvals and amendments are retained permanently; nothing in this folder is ever deleted.
