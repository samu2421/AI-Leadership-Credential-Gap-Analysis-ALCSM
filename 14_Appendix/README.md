# 14_Appendix

## Purpose
Supplementary material referenced in the thesis but not part of the main body.

## What Belongs Here
- Full codebooks and extended data tables
- Copies of IRB documents referenced in appendices
- Additional analysis not central to the main narrative
- Survey/annotation instruments in full

## Naming Conventions
- `ALCSM_Appendix<Letter>_<Description>_v<Major>.<Minor>.<ext>`
  - e.g., `ALCSM_AppendixB_AnnotationCodebook_v1.0.pdf`
- Appendix letters (A, B, C, ...) must match the final manuscript's appendix references once assigned.

## Versioning Rules
- Standard MAJOR.MINOR versioning; never overwrite an appendix once cross-referenced in the manuscript — bump the version instead.
- Superseded appendix versions move to `16_Archive/14_Appendix/`.
