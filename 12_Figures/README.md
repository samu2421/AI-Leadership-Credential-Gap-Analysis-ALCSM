# 12_Figures

## Purpose
All figures used in the thesis manuscript — charts, diagrams, and model visuals — in both source and exported form.

## What Belongs Here
- Source files (e.g., `.ai`, `.pptx`, `.fig`, plotting scripts/notebooks)
- Exported final images (`.png`, `.svg`, `.pdf`) referenced by chapter and figure number

## Naming Conventions
- `ALCSM_Fig<ChapterNum>.<FigNum>_<Description>_v<Major>.<Minor>.<ext>`
  - e.g., `ALCSM_Fig3.2_FrameworkOverview_v1.0.png` (Chapter 3, Figure 2)

## Versioning Rules
- Figure numbering must stay stable once referenced in a thesis draft — never renumber a figure that's already cited in `11_Thesis_Writing`.
- Content revisions bump the version suffix rather than changing the figure number; superseded versions move to `16_Archive/12_Figures/`.
